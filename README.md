# BSRA Reinforcement Learning

This is the learning and research hub for the Reinforcement Learning subteam of the [Boiler Soccer Robots Association](https://github.com/Fabricio-Giusti/BSRA-Documentation). We study how agents can learn useful humanoid-soccer behaviors in simulation and, eventually, transfer them to a robot.

> **New member? [Start with the orientation](ORIENTATION.md) before the next meeting.** No installation or coding is required.

## What belongs here

- Guided learning material and shared vocabulary
- Curated references to trustworthy external resources
- Small, fixed onboarding exercises
- Links to BSRA RL projects as they are created

Production robot skills, long-running experiments, trained policies, and member submissions belong in separate repositories.

## Learning path

1. Complete the [orientation](ORIENTATION.md).
2. See how the team's [toolchain](resources/toolchain.md) fits together.
3. Return for the upcoming [cart-pole onboarding assignment](onboarding/README.md).
4. Move into a separate project repository when you receive a team assignment.

## Initial toolchain

We use **MuJoCo** for physics, **Gymnasium** for the environment interface, **Stable-Baselines3** for RL algorithms, **PyTorch** as the learning backend, and **TensorBoard** for experiment tracking. See [the toolchain overview](resources/toolchain.md) for each tool's role.

## Contributing

Keep additions focused and beginner-friendly. A new resource should include why it helps, what to read, and the date it was checked. Prefer improving or replacing an entry over growing an unranked link list, and keep datasets, checkpoints, logs, and videos out of Git.
