# Resources

This directory contains a small, maintained path—not a catalog of everything related to RL.

## Labels

- **Required now:** complete before the next meeting.
- **Required for onboarding:** complete when the related assignment asks for it.
- **Recommended:** useful context or another explanation.
- **Reference:** consult when you need a specific detail.

Every entry should say why it is included, what part to use, what you should take away, and when its link was last checked. We favor official documentation, original research, and durable teaching material.

- [Orientation reading list](reading-list.md)
- [Toolchain overview](toolchain.md)

Deeper readings will be added when the learning path reaches them. A resource earns a place here by supporting a clear learning outcome, not merely by being interesting.
